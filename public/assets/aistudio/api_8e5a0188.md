# Elli – API Endpoints

The Elli agent exposes a local HTTP API (default `http://127.0.0.1:8741`) so the Dashboard UI and external tools can interact with it. All endpoints require authentication except health and login.

**Base URL**: `http://127.0.0.1:8741/api/v1`

---

## 1. Authentication

| Method | Endpoint              | Description                  | Auth |
|--------|-----------------------|------------------------------|------|
| POST   | `/auth/login`         | Login with username/password | No   |
| POST   | `/auth/logout`        | Invalidate current token     | Yes  |
| GET    | `/auth/me`            | Current user info            | Yes  |
| POST   | `/auth/refresh`       | Refresh JWT                  | Yes  |

### Login Request
```json
{
  "username": "alex",
  "password": "..."
}
```

### Login Response
```json
{
  "access_token": "eyJ...",
  "token_type": "bearer",
  "expires_in": 86400,
  "user": {
    "id": 1,
    "username": "alex",
    "role": "admin"
  }
}
```

## 2. Agent Core

| Method | Endpoint                | Description                              | Auth |
|--------|-------------------------|------------------------------------------|------|
| POST   | `/agent/prompt`         | Submit text prompt                       | Yes  |
| POST   | `/agent/voice`          | Upload audio for transcription + run     | Yes  |
| GET    | `/agent/status`         | Current state machine status             | Yes  |
| POST   | `/agent/cancel`         | Cancel running action                    | Yes  |
| GET    | `/agent/history`        | Recent chat + action history             | Yes  |

### Prompt Request
```json
{
  "text": "create a file named today_quotes and fetch inspirational quotes",
  "session_id": "optional-uuid"
}
```

### Prompt Response (async pattern)
```json
{
  "request_id": "req_abc123",
  "status": "planning"   // or "awaiting_confirmation", "executing", "completed", "error"
}
```

## 3. Gatekeeper

| Method | Endpoint                     | Description                          | Auth |
|--------|------------------------------|--------------------------------------|------|
| GET    | `/gatekeeper/pending`        | Get current pending action preview   | Yes  |
| POST   | `/gatekeeper/confirm`        | Confirm pending action               | Yes  |
| POST   | `/gatekeeper/deny`           | Deny pending action                  | Yes  |
| POST   | `/gatekeeper/edit`           | Submit edited content / path         | Yes  |
| POST   | `/gatekeeper/trust`          | Mark pattern as trusted              | Yes  |

### Confirm / Deny / Edit Body
```json
{
  "request_id": "req_abc123",
  "edited_content": "optional new text",
  "edited_path": "optional new filename"
}
```

## 4. Filesystem & Tools

| Method | Endpoint                  | Description                     | Auth |
|--------|---------------------------|---------------------------------|------|
| GET    | `/workspace/list`         | List files in agent_workspace   | Yes  |
| GET    | `/workspace/file`         | Read file content               | Yes  |
| POST   | `/workspace/restore`      | Restore from trash              | Yes  |
| GET    | `/trash/list`             | List soft-deleted files         | Yes  |
| DELETE | `/trash/empty`            | Empty trash (with confirmation) | Yes  |

---

## 7. Common Response Envelope

Success:
```json
{
  "success": true,
  "data": { ... },
  "request_id": "..."
}
```

Error:
```json
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Path outside sandbox",
    "details": {}
  }
}
```

## 8. Authentication Header

```
Authorization: Bearer <access_token>
```

All state-changing endpoints should also accept an optional `X-Request-ID` for tracing.
